# Digital Odyssey Guides

This repository contains the source files for my **Digital Odyssey guides** published on [Odyssey Calc](https://odyssey-calc.com/#/guides).

The repository is mainly used for **version control, guide maintenance, and community feedback**.

Digital Odyssey is a private server for the game DMO (Digimon Master Online).
<br/>Server website link: https://thedigitalodyssey.com/
<br/>Server Discord link: https://discord.thedigitalodyssey.com/

## Repository Structure

Most of the repository consists of:

- `.md` files containing the guides.
- Image directories containing the images used by the guides.

You generally only need to edit the relevant Markdown file when updating guide content.

## Providing Feedback

If you find:

- Incorrect or outdated information
- Typos or unclear explanations
- Missing information
- A better progression or recommendation
- Broken images or formatting

please open a **GitHub Issue**.

When creating an issue, provide:

1. A short, descriptive title.
2. The guide or section concerned.
3. What you believe is incorrect or could be improved.
4. Any relevant details, screenshots, or sources if applicable.

Issues are preferred over directly modifying the guides when you only want to suggest a change.

## Modifying the Guides

If you want to directly contribute a correction or improvement:

1. Fork the repository.
2. Modify the relevant `.md` file.
3. Add or update images in the appropriate image directory if necessary.
4. Commit your changes with a clear message.
5. Open a **Pull Request**.

Keep changes focused on the relevant guide and avoid unrelated formatting changes.

## Images

Images used by guides are stored in the repository.

When adding an image:

- Place it in a appropriate image folder.
- Use a descriptive filename.
- Reference it from the Markdown file using this format: `![New Image](folder/filename.png)`.

## Publishing

The repository is the **source of truth** for the guides.

After changes are reviewed, I use the updated Markdown files and image directories to update the guides on the website.
The website content needs to be manually changed by me (Yvelchrome) or other editors I set.
