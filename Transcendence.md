This guide explains the transcendence system (also known as **6/6**).

Besides allowing digimon to grow up to 140% size, transcendence also unlocks HP Cloning, making it an important progression milestone for every digimon you plan to use long-term.

It focuses on how the system works, the requirements to unlock it, and recommended usage.

---

## Requirement

To access transcendence (6/6), your digimon must meet the following requirements:

- Must be a **5/5 digimon** (Or be a **3/3 Hybrid** or **ExtraOrdinary** digimon)
- Must have at least **125% size**
- Must be at least **Level 100**

Transcendence is available for all digimon.

Upon transcending a digimon, you also unlock HP cloning for that digimon, allowing you to further increase its maximum HP through the cloning system.

---

## Transcendence Cost

Performing transcendence requires **5T**.

> This cost is paid each time you transcend a digimon.

---

## Digimon Size Upgrade

Before Transcendence, the maximum digimon size is **130%**.
After transcendence, digimons can exceed this limit and reach a maximum size of **140%**.

### Size Fruits

Two fruits can increase digimon size beyond the previous limit:

| Fruit                | Size Range           |
| -------------------- | -------------------- |
| [[item:il2cm8]] | 125% - 140% |
| Fruit of Homeostasis | 128% - 140%          |

> Both fruits increase size randomly within their available range.

> Using a fruit cannot decrease your digimon's size.

#### Obtaining Fruits

Currently, these fruits can be obtained reliably through:

- RNG Boxes obtained from [Diablomon N/H](https://share.odyssey-calc.com/guides/dungeon-boss-locations?v=5&section=diablomon).
- Daily playtime rewards (10 [[item:il2cm8]] per day).
- Daily exchange NPC rewards (up to 30 [[item:il2cm8]] per day).
- The market.

### Recommended Size

**140%** is the maximum size, but **138%+** is a good stopping point for most players.

Going to 140% is mainly a min-max upgrade for players who want to maximize their digimon.

> Reminder: Every size increase boosts a digimon's base stats by the same amount (1% size = 1% more base stats).

## Transcendence EXP

Transcendence EXP is gained by consuming other digimons.
The amount gained depends on the **level, clone levels, hatch phase, species** of the digimon being consumed and the **transcendence data type** used.

### Base EXP Example

A **different-species 5/5 Digimon** at **Lv1** with **0 clone levels** provides **7.17%** Transcendence EXP.

Higher levels and clone levels increase the EXP gained.
A **different-species 5/5 Digimon** at **Lv60** with **12 clone levels** provides **10.57%** Transcendence EXP.

> Clone levels refers to the **total number of clones on the digimon**, not each individual stat.

### EXP Formula

**Transcendence % = (Clone levels x 5 + Level + 250) x Hatch Phase x Data Type / 1400**

| Value           | Description                                                         |
| --------------- | ------------------------------------------------------------------- |
| **Clone levels**| Total number of clones on the digimon. Each clone adds **5**.       |
| **Level**       | Current digimon level.                                              |
| **Base**        | Fixed base value (**250**).                                         |
| **Hatch Phase** | Depends on hatch phase and whether the digimon is the same species. |
| **Data Type**   | **1.0** for Low, **1.6** for Mid.                                   |
| **140,000**     | Total EXP required for Transcendence.                               |

| Hatch Phase | Different Species | Same Species |
| ----------- | ----------------: | -----------: |
| Lv3         |                 1 |            3 |
| Lv4         |                10 |           30 |
| Lv5         |                40 |          120 |

#### Formula Example

A **same-species 5/5 digimon**, **Lv55** with **12 clone levels**, and **Mid Data Type** provides:

(**12** x 5 + **55** + 250) x **120** × **1.6** / 1400 = 50.06%

So it provides **50.06% of the 140,000 Transcendence EXP**.

## Transcendence Charges

There are two ways to perform transcendence:

### Regular Charge

Uses a **Low-Class** Transcendence ConvertChip.
Final multiplier: **x1 EXP**

### Hyper Charge

Uses a **Mid-Class** Transcendence ConvertChip.
Final multiplier: **x1.6 EXP**

#### Obtaining Mid-Class Chips

You can get them by :

- Buying them in the cash shop (3c each)
- Crafting them at Zudomon in the Olympos map.
- Buying them on the market.

> The cash shop could be the cheapest way to obtain them, check out the [[item:i1vbb0ab|Crown Token (10C)]] price on the market.

### Chip Cost

Each charge consumes 1 chip **per** digimon consumed.

## Same Species Bonus

Using a copy of the **same digimon species** as the digimon being transcended (for example, [[digimon:dfwwn6s|Agumon(Classic)]] -> [[digimon:dfwwn6s|Agumon(Classic)]]) triples the base EXP gained.

Example:

A different-species 5/5 digimon Level 1 with 0 clone levels: 7.17%

Same species bonus:
7.17% × 3 = **21.51%**

With Hyper Charge:
21.51% × 1.6 = **34.416%**

---

## Raremon Exception

[[digimon:d1968bbg|Raremon]] is a special digimon line for transcendence.

Unlike normal digimons, Raremon provides a fixed amount of transcendence EXP regardless of its level or clone levels.

| Digimon     | Regular Charge | Hyper Charge |
| ----------- | -------------- | ------------ |
| 3/5 Raremon | 2.24%          | 3.58%        |
| 4/5 Raremon | 16.82%         | 26.91%       |
| 5/5 Raremon | 44.85%         | 71.76%       |

If you obtain a 5/5 Raremon, its primary use is usually as transcendence material.

## Recommended Combinations

> All examples below assume **Hyper Charge (Mid-Class Chip)**.

> Clone levels can be split between any of the four clone stats, as long as the total equals the required amount.

- 1 same-species 5/5 Lv.1 digimon, 0 clone levels + 1 Raremon 5/5
- 2 same-species 5/5 lv.1 digimons, 23 clone levels each
- 2 same-species 5/5 lv.55 digimons, 12 clone levels each
- 3 same-species 5/5 Lv.1 digimons, 0 clone levels each
